Scenarios for Azure networking services including Virtual Networks, Load Balancers, and VPN.

## Available Scenarios

| Scenario | Description | Complexity |
|:---------|:------------|:-----------|
| [Virtual Network](../networking-01-virtual-network/) | VNet with subnets | Low |
| [VPN Gateway](../networking-02-vpn-gateway/) | Site-to-site VPN | High |
| [Load Balancer](../networking-03-load-balancer/) | Azure Load Balancer | Medium |
| [Application Gateway](../networking-04-application-gateway/) | Layer 7 load balancing | High |
| [Private Endpoint](../networking-05-private-endpoint/) | Private connectivity | Medium |

## Technologies Used

- Azure Virtual Network
- Azure VPN Gateway
- Azure Load Balancer
- Azure Application Gateway
- Private Endpoints

## Prerequisites

- Azure subscription with networking services enabled
- IP address planning for VNets
- Certificate management for Application Gateway
