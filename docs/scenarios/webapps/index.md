# Web App Scenarios
{: .no_toc }

Scenarios for Azure web application services including Static Web Apps and API Management.
{: .fs-6 .fw-300 }

---

## Available Scenarios

| Scenario | Description | Complexity |
|:---------|:------------|:-----------|
| [Static Website](../webapps-01-static-website/) | Blob storage static site | Low |
| [Node.js App Service](../webapps-02-nodejs-app-service/) | Node.js web app | Low |
| [Docker App Service](../webapps-03-docker-app-service/) | Containerized app | Medium |
| [Static Web Apps](../webapps-04-static-web-apps/) | SWA with Functions | Medium |
| [API Management](../webapps-05-api-management/) | API gateway | High |

## Technologies Used

- Azure Blob Storage (Static Sites)
- Azure App Service
- Azure Static Web Apps
- Azure API Management
- Azure Container Registry

## Prerequisites

- Azure subscription with web services enabled
- Custom domain (optional)
- SSL certificates (optional)
