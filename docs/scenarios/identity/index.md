# Identity Scenarios
{: .no_toc }

Scenarios for Azure identity and access management including Entra ID and RBAC.
{: .fs-6 .fw-300 }

---

## Available Scenarios

| Scenario | Description | Complexity |
|:---------|:------------|:-----------|
| [Service Principals](../identity-01-service-principals/) | App identity management | Medium |
| [RBAC Assignments](../identity-02-rbac-assignments/) | Role-based access control | Medium |
| [Entra Users & Groups](../identity-03-entra-users-groups/) | User management | Low |
| [App Registrations](../identity-04-app-registrations/) | Application registration | Medium |
| [Conditional Access](../identity-05-conditional-access/) | Access policies | High |

## Technologies Used

- Microsoft Entra ID (Azure AD)
- Azure RBAC
- App Registrations
- Service Principals
- Conditional Access Policies

## Prerequisites

- Microsoft Entra ID tenant
- Global Administrator or appropriate admin roles
- Azure subscription linked to Entra tenant
